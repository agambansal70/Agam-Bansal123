# My Portfolio

## About

A personal portfolio website built for Builders Day. It shows who I am, what I know, and what I've built, using a bold "sticker sheet" style: thick outlines, hard offset shadows, and flat bright colours. It includes a floating code window in the hero, a scrolling skills strip, and a bento-grid skills section.

## Technologies

- HTML
- CSS (Flexbox, Grid, positioning, media queries, transitions, keyframe animations)

No JavaScript is used.

### Responsive Website
